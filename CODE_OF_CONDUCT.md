# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as adopted across the [Nebari](https://nebari.dev) community.

In short: be respectful and constructive; harassment and exclusionary behavior
are not tolerated. The full text of the standards and enforcement guidelines is
in the Contributor Covenant linked above.
