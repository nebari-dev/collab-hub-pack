# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public
issue or pull request.

Preferred: use GitHub's **[Report a vulnerability](https://github.com/nebari-dev/collab-hub-pack/security/advisories/new)**
(the Security tab → "Report a vulnerability"), which opens a private advisory
with the maintainers.

<!-- CONFIRM: alternate contact address before launch. -->
If you cannot use GitHub advisories, email **security@openteams.com**.

Please include steps to reproduce, affected versions, and impact. We will
acknowledge receipt, work with you on a fix and disclosure timeline, and credit
you unless you prefer otherwise.

## Supported versions

This project is pre-1.0; security fixes land on the latest released version.
